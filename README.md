## Projects

### [Square Distance Game](https://github.com/hwornick/square-distance-game)
A quick little math puzzle game. You get a grid with some highlighted target cells and try to find the cell that minimizes the total squared distances to all of them. It's a fun way to build intuition for least-squares optimization. [Play it here.](https://square-distance-game.vercel.app/)

### [Draftprep](https://github.com/hwornick/draftprep)
A Python script I wrote to generate a cheatsheet for my fantasy baseball auction draft. It pulls in projections and historical league data, runs a valuation model, and spits out a formatted Excel workbook I can use on draft day. I've been tweaking it for years — league champion in 2016 and 2025, with division titles in 2019 and 2020! The spreadsheet helps.
